## 회의 전
### 전날 진행한 사항
전체 파이프라인 이해
### 금일 진행할 사항
UI/UX 디자인 진행
### 현재 발생한, 혹은 발생할 것으로 예상되는 이슈
(특이사항 없음)

## 회의 후
### 논의사항
평가 데이터셋을 만드는 근본적인 이유와, 이를 구축하는 순서에 대한 이해
### 논의 결과
- 전체 파이프라인을 먼저 이해한 뒤 각자 파트를 진행하는 것이 효율적이라는 데 합의함
- 현재 크롤링, 청킹까지는 완료했으나, 임베딩 이후 단계(검색, 평가, 생성)는 팀원 전체의 추가 학습이 필요한 상황으로 확인됨
| 단계 | 검토 중인 선택지 |
| --- | --- |
| 질의 분류 | 키워드 매칭 / 임베딩 유사도 / LLM 분류 — 3가지 방식 중 검토 중 |
| 검색 방법 | 코사인(Dense) / BM25(키워드) / Hybrid — 어떤 조합으로 갈지 검토 중 |
| 검색 고도화 | Reranking, Parent-Child Retrieval 등 추가 튜닝 여부 검토 중 |
| 생성 기법 | 프롬프트 기반 생성 방식을 어떻게 설계할지 논의 중 |
